LogSense Documentation

LogSense is a developer tool designed to analyze log files and help engineers quickly understand system failures. Instead of manually reading thousands of log lines, LogSense automatically highlights the most important errors and builds a timeline of failures.

Getting Started

Download the LogSense desktop application from the downloads page and launch the program.

LogSense.exe

Opening Logs

Click the Open Log button in the top navigation bar and select a log file.

Supported file types

.log
.txt

Understanding the Report

Once a log file is loaded, LogSense generates an incident report.

LOGSENSE INCIDENT REPORT
--------------------------------

Lines scanned: 12043
Errors found: 245

Root Cause Candidate
DatabaseTimeoutException

Timeline
2026-03-10 10:21:05 → DatabaseTimeoutException
2026-03-10 10:21:07 → APIServiceException

Top Issues
1. DatabaseTimeoutException -> 117
2. APIServiceException -> 82

Root Cause Candidate

The root cause candidate is the earliest detected error in the timeline. This is often the event that triggered a cascade of failures.

Timeline

The timeline shows the order in which errors occurred so developers can understand how a failure propagated through the system.

Top Issues

The top issues section highlights the most frequent errors in the log file.
