LogSense Documentation

Learn setup, usage patterns, and practical examples for production-ready log analysis.

Setup

1. Download the latest build from Downloads.

2. Open your project logs folder.

3. Run the CLI command below.

logsense analyze app.log

Usage

Use filters to focus on severity, service, and timeline windows.

logsense analyze app.log --severity error logsense analyze app.log --service auth-api

Examples

Export AI summary reports to share with your team during incidents.

logsense export report.json --format markdown logsense export report.json --format html
